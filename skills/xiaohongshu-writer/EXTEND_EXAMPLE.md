# 小红书写作风格自定义示例

> 此文件展示如何自定义小红书 Skill 的写作风格

## 使用方法

将此文件复制到以下位置之一：

```bash
# 用户级（个人偏好）
mkdir -p ~/.claude-skills/xiaohongshu-writer
cp EXTEND_EXAMPLE.md ~/.claude-skills/xiaohongshu-writer/EXTEND.md

# 项目级（团队共享）
mkdir -p .claude-skills/xiaohongshu-writer
cp EXTEND_EXAMPLE.md .claude-skills/xiaohongshu-writer/EXTEND.md
```

## 配置示例 1：专业品牌风格

```markdown
# 品牌风格：专业科技

## 语气调整
- 减少口语化：避免"姐妹们"、"绝了"、"yyds"等网络用语
- 保持专业但亲和：用"大家"、"朋友们"替代
- Emoji 使用：每段最多 1-2 个，优先使用 ✨💡🔍📊 等专业图标

## 品牌信息
- 品牌名：智能生活研究所
- 主营：智能硬件评测与推荐
- 目标用户：25-40 岁科技爱好者、数码产品用户
- 调性：专业、客观、实用

## 标题策略
- 优先公式：数字 + 场景 + 结果
- 示例：「3 款智能音箱横评，这款性价比最高」
- 避免：过度悬念、夸张表达

## 标签策略
- 优先标签：#智能硬件 #科技评测 #数码好物
- 品牌标签：#智能生活研究所
- 避免：过于娱乐化的标签

## 内容结构
- 开头：直接说结论或核心观点
- 正文：数据 + 实测 + 对比
- 结尾：总结 + 购买建议（不过度营销）
```

## 配置示例 2：时尚美妆风格

```markdown
# 品牌风格：时尚美妆

## 语气调整
- 保持活泼：可以使用"姐妹们"、"宝子们"
- Emoji 丰富：💄✨🌸💕🎀 等可爱元素
- 语气词：可以用"啦"、"呀"、"哦"

## 品牌信息
- 品牌名：小美的美妆日记
- 主营：美妆护肤分享
- 目标用户：18-30 岁女性
- 调性：亲切、时尚、分享感

## 标题策略
- 优先公式：人群 + 痛点 + 解决方案
- 示例：「敏感肌姐妹看过来！这款精华真的温和」
- 可以使用：感叹号、疑问句

## 标签策略
- 优先标签：#美妆分享 #护肤心得 #好物推荐
- 热门标签：#OOTD #每日穿搭 #变美日记
- 互动标签：#姐妹们都在用

## 内容结构
- 开头：痛点共鸣或惊喜分享
- 正文：使用感受 + 效果展示 + 小tips
- 结尾：互动提问，引导评论
```

## 配置示例 3：知识干货风格

```markdown
# 品牌风格：知识干货

- 简洁直接：少用修饰词

- 优先公式：工具/方法 + 效果 + 场景
- 示例：「这个笔记方法，让我考试效率提升 50%」

## 标签策略
- 优先标签：#效率工具 #学习方法 #职场技能
- 场景标签：#学生党必备 #打工人自救

- 开头：痛点 + 解决方案预告
- 正文：步骤化教程（Step 1/2/3）
```

## 高级配置：多场景切换

如果你需要在不同场景使用不同风格，可以创建多个配置文件：

```bash
# 创建配置库
mkdir -p ~/.claude-skills-configs/xiaohongshu-writer

# 保存不同风格
~/.claude-skills-configs/xiaohongshu-writer/
├── professional.md    # 专业风格
├── casual.md          # 活泼风格
├── knowledge.md       # 知识干货
└── lifestyle.md       # 生活方式

# 使用时切换
cp ~/.claude-skills-configs/xiaohongshu-writer/professional.md \
   .claude-skills/xiaohongshu-writer/EXTEND.md
```


检查要点：
- ✅ 语气是否符合配置
- ✅ Emoji 使用频率是否正确
- ✅ 标题风格是否匹配
- ✅ 标签是否包含品牌标签

## 更多技巧

### 1. 使用反例
在配置中明确说明"不要做什么"：

```markdown
## 标题风格

❌ 避免：「震惊！这款产品竟然...」
❌ 避免：「姐妹们冲！！！」
✅ 推荐：「实测 3 款智能手表，这款最值得买」
```

### 2. 提供模板
为常见场景提供模板：

```markdown
## 产品推荐模板

标题：[数字] + [产品类别] + [核心卖点]
开头：为什么需要这个产品（痛点）
正文：
  - 产品 1：[名称] - [优点] - [适合人群]
  - 产品 2：[名称] - [优点] - [适合人群]
  - 产品 3：[名称] - [优点] - [适合人群]
结尾：总结 + 选购建议
```

### 3. 定期更新
根据平台趋势和用户反馈，定期更新配置：

```markdown
## 更新日志

- 2026-01-18：增加视频号联动标签
- 2026-01-10：调整 Emoji 使用策略
- 2026-01-01：更新品牌标签
```

---

**提示**：选择最适合你的风格，不要过度配置。从一个简单的配置开始，根据实际效果逐步调整。
