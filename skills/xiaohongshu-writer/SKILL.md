# 小红书爆款笔记生成器

## 触发条件

当用户需要创作小红书笔记、种草文案、或小红书风格内容时激活。

## 平台特性

- **用户画像**：18-35岁女性为主，追求品质生活
- **内容调性**：真实、有用、有趣、有共鸣
- **核心价值**：种草、分享、记录生活

## 爆款公式

### 标题公式（二选一）

**公式A：数字+痛点+解决方案**
```
❌ 护肤心得分享
✅ 熬夜党必看！3步拯救暗沉肌，7天白回来
```

**公式B：人群+场景+利益点**
```
❌ 穿搭推荐
✅ 小个子女生看过来！显高10cm的穿搭秘籍
```

### 标题元素
- 🔢 数字：具体数字增加可信度（3个、7天、100元）
- 😱 情绪词：绝了、救命、yyds、绝绝子
- 🎯 人群标签：学生党、打工人、宝妈、小个子
- ❓ 疑问/悬念：竟然、居然、没想到

## 正文结构

```markdown
【开头Hook】（前3行决定是否继续看）
- 痛点共鸣："姐妹们是不是也有这个困扰..."
- 结果前置："用了这个方法，我终于..."
- 反常识："原来我们一直都做错了！"

【正文内容】
- 分点叙述，每点不超过3行
- 多用emoji分隔，增加可读性
- 穿插个人体验，增加真实感

【结尾互动】
- 提问引导评论："你们觉得呢？"
- 收藏引导："先码住！"
- 关注引导："关注我，持续分享..."
```

## 注意事项

1. **真实性**：避免过度夸张，保持可信度
2. **原创性**：不要直接复制，要有个人风格
3. **合规性**：避免违禁词，不做虚假宣传
4. **互动性**：引导用户评论、收藏、关注
