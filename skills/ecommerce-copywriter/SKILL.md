# 电商文案生成器

## 触发条件

当用户需要创作电商产品文案、详情页、主图文案时激活。

## 平台特性

| 平台 | 用户特点 | 文案风格 |
|------|----------|----------|
| 淘宝 | 追求性价比 | 活泼、促销感强 |
| 京东 | 注重品质 | 专业、可信赖 |
| 拼多多 | 价格敏感 | 直接、实惠感 |
| 抖音电商 | 冲动消费 | 场景化、情绪化 |

## 文案结构

### FABE法则
- **F (Feature)**：产品特点
- **A (Advantage)**：产品优势
- **B (Benefit)**：用户利益
- **E (Evidence)**：证据支撑

### 痛点-方案-证明
```
痛点：你是不是也有[问题]？
方案：我们的产品可以[解决方案]
证明：[数据/案例/背书]
```

## 文案技巧

### 数字化表达
```
❌ 效果很好
✅ 98%用户反馈有效

❌ 很多人购买
✅ 累计销量100万+

❌ 快速发货
✅ 下单后24小时内发货
```

### 场景化描述
```
❌ 保温效果好
✅ 早上装的热水，下班还是烫嘴

❌ 容量大
✅ 一次能装下3天的换洗衣服
```

### 对比强化
```
❌ 价格实惠
✅ 同品质产品，我们便宜30%

❌ 质量好
✅ 别家用1年，我们用3年
```

## 注意事项

1. **合规性**：避免极限词（最、第一、绝对）
2. **真实性**：数据要有依据，不虚假宣传
3. **平台规则**：遵守各平台广告法规定
4. **差异化**：突出与竞品的区别
