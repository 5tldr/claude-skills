## 配置示例 1：科技教程风格

```markdown
# 漫画风格：科技教程

## 默认风格
- 首选：tech（科技风格）
- 备选：ohmsha（日式技术漫画）

## 默认布局
- 首选：standard（标准布局，4-6 格/页）
- 画面比例：3:4（竖版，适合移动阅读）

## 视觉风格
- 色调：深色背景 + 霓虹色强调
- 主色：#6366F1（紫色）
- 辅色：#10B981（绿色）
- 背景：#0F172A（深蓝灰）

## 角色设定
- 导师：机器人形象，戴眼镜，友好
- 学生：年轻人，好奇，积极提问
- 风格：简化、可爱、易识别

## Midjourney 参数
- 默认风格化：--s 250
- 默认版本：--v 6.1
- 附加参数：--no text, realistic photos

## 内容偏好
- 每格信息量：1-2 个要点
- 对话长度：每句不超过 15 字
- 视觉隐喻：多使用科技元素（电路、代码、几何图形）
- 节奏：快速、信息密集

## 页数建议
- 短教程（<1000 字）：4-6 页
- 中教程（1000-2000 字）：8-12 页
- 长教程（>2000 字）：15-20 页
```

## 配置示例 2：人物传记风格

```markdown
# 漫画风格：人物传记

## 默认风格
- 首选：classic（传统清线风格）
- 备选：sepia（复古风格，适合历史人物）

## 默认布局
- 首选：cinematic（电影感布局，2-4 格/页）
- 画面比例：4:3（横版，适合叙事）

## 视觉风格
- 色调：温暖、怀旧
- 主色：根据时代背景选择
- 线条：清晰、统一
- 背景：细致、时代准确

## 叙事结构
- 三幕式：童年 → 成就 → 影响
- 节奏：舒缓、有张力
- 高潮：用大格或跨页展示

## Midjourney 参数
- 默认风格化：--s 200
- 默认版本：--v 6.1
- 附加参数：--no text, modern elements

## 内容偏好
- 每格信息量：注重情感和氛围
- 对话：符合人物性格和时代背景
- 旁白：提供历史背景和解释
- 节奏：张弛有度，情感饱满

## 页数建议
- 短传记（生平概述）：8-12 页
- 中传记（重点事件）：15-20 页
- 长传记（完整生平）：30-40 页
```

## 多场景配置切换

```bash

mkdir -p ~/.claude-skills-configs/knowledge-comic

# 保存不同场景配置
~/.claude-skills-configs/knowledge-comic/
```

## 角色一致性配置

```markdown
# 角色一致性设置

## 主要角色

### 角色 1：导师
- 外貌：中年男性，戴眼镜，短发
- 服装：白色实验服或休闲衬衫
- 性格：友好、耐心、博学
- 口头禅：「让我们来看看...」

**Midjourney 角色参考**：
```
Middle-aged male teacher with glasses and short hair,
wearing white lab coat, friendly expression,
[风格] style
--cref [参考图 URL]
```

### 角色 2：学生
- 外貌：年轻女性，马尾辫，大眼睛
- 服装：休闲装，背包
- 性格：好奇、积极、爱提问
- 口头禅：「原来如此！」

**Midjourney 角色参考**：
```
Young female student with ponytail and big eyes,
wearing casual clothes with backpack, curious expression,
[风格] style
--cref [参考图 URL]
```

## 角色一致性技巧

1. **使用 --cref 参数**：
   ```
   --cref [第一格生成的角色图 URL]
   ```

2. **详细描述**：
   - 每次都包含完整的角色描述
   - 保持关键特征一致

3. **风格统一**：
   - 所有格使用相同的风格参数
   - 保持 --s 值一致

4. **后期处理**：
   - 如果 AI 生成不一致，可以手动调整
   - 使用 Photoshop 或 Procreate 统一风格
```

## 常见问题

### Q: 如何保持角色一致性？

A: 
1. 使用 Midjourney 的 `--cref` 参数
2. 在每个 Prompt 中包含完整的角色描述
3. 保持风格参数一致
4. 必要时手动后期调整

### Q: 如何控制信息密度？

A: 
- 调整布局类型（standard/dense/cinematic）
- 设置每格信息量限制
- 控制对话长度

### Q: 如何选择合适的风格？

A: 根据内容和受众：
- 儿童：vibrant, warm
- 技术：tech, ohmsha
- 历史：sepia, classic
- 专业：realistic, classic

### Q: 页数太多怎么办？

A: 
- 精简内容，只保留核心要点
- 使用 dense 布局增加信息密度
- 分成多个系列

## 更多技巧

### 1. 视觉隐喻库

建立常用的视觉隐喻：

```markdown
## 常用视觉隐喻

- 学习：灯泡亮起
- 困惑：头顶问号
- 理解：拼图完成
- 数据：流动的河流
- 算法：齿轮转动
- 网络：蜘蛛网
- 速度：闪电
- 成长：植物发芽
```

### 2. 情绪表达

为角色定义情绪表达：

```markdown
## 情绪表达指南

- 惊讶：眼睛放大，嘴巴张开
- 困惑：眉头紧皱，歪头
- 理解：眼睛发光，微笑
- 兴奋：跳跃，双手举起
- 思考：手托下巴，眼神向上
```

### 3. 分镜节奏

定义不同场景的节奏：

```markdown
## 分镜节奏指南

- 开场：2-3 格，建立场景
- 解释：4-6 格，详细展开
- 高潮：1-2 大格，强调重点
- 过渡：2-3 格，承上启下
- 结尾：2-3 格，总结升华
```
