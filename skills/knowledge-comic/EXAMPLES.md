## 示例 1：技术教程 - 什么是机器学习

### 输入

```
我：帮我创作一个知识漫画，主题是"什么是机器学习"
要求：
- 风格：ohmsha（日式技术漫画）
- 布局：standard（标准布局）
- 目标受众：初学者
- 页数：6-8 页
```

### 输出概览

**漫画信息**：
- 标题：《机器学习入门》
- 风格：Ohmsha（日式技术漫画）
- 布局：Standard（4-6 格/页）
- 总页数：8 页
- 总格数：36 格

**故事大纲**：
1. 第一幕：什么是机器学习（2 页）
2. 第二幕：机器学习如何工作（4 页）
3. 第三幕：机器学习的应用（2 页）

### 分镜示例（第 1 页）

#### 格 1：开场

**画面**：
- 场景：教室，黑板上写着"机器学习"
- 人物：机器人老师（戴眼镜）和学生小美（马尾辫）
- 焦点：老师指着黑板
- 情绪：友好、欢迎

**对话**：
- 老师：「今天我们来学习机器学习！」
- 小美：「听起来好复杂...」

**Midjourney Prompt**：
```
Friendly robot teacher with glasses pointing at blackboard,
young female student with ponytail looking curious,
Japanese manga guide style, educational manga aesthetic,
classroom setting, warm lighting, cute characters,
clean linework, professional quality
--ar 3:4 --v 6.1 --s 200 --no text
```

#### 格 2：什么是机器学习

**画面**：
- 场景：思维泡泡中展示大脑和电脑连接
- 人物：小美在思考
- 焦点：大脑-电脑连接的视觉隐喻
- 情绪：好奇、理解

**旁白**：
机器学习就是让电脑像人一样学习！

**Midjourney Prompt**：
```
Thought bubble showing brain connected to computer,
visual metaphor for machine learning,
Japanese manga guide style, cute illustration,
simple and clear, educational diagram,
clean linework, pastel colors
--ar 3:4 --v 6.1 --s 200 --no text
```

#### 格 3：传统编程 vs 机器学习

**画面**：
- 场景：分屏对比
- 左侧：程序员写代码（规则）
- 右侧：电脑自己学习（数据）
- 焦点：对比差异

**对话**：
- 老师：「传统编程是人写规则，机器学习是机器自己找规则！」

**Midjourney Prompt**：
```

right side: computer learning from data,
Japanese manga guide style, clear visual contrast,
arrows and icons, educational illustration
--ar 3:4 --v 6.1 --s 200 --no text
```

## 使用技巧总结

### 1. 选择合适的风格

| 内容类型 | 推荐风格 | 原因 |
|---------|---------|------|
| 技术教程 | ohmsha, tech | 视觉隐喻清晰，易于理解 |
| 人物传记 | classic, sepia | 叙事性强，适合长篇 |
| 儿童教育 | vibrant, warm | 色彩明亮，吸引注意 |
| 历史事件 | sepia, dramatic | 时代感强，氛围到位 |
| 商业故事 | realistic, classic | 专业感强，可信度高 |

### 2. 选择合适的布局

| 内容特点 | 推荐布局 | 原因 |
|---------|---------|------|
| 信息密集 | dense | 可以容纳更多内容 |
| 情感叙事 | cinematic | 节奏舒缓，有张力 |
| 快速教程 | standard | 平衡信息量和可读性 |
| 关键时刻 | splash | 强调重点，震撼力强 |
| 移动阅读 | webtoon | 适合手机竖屏阅读 |

### 3. 控制页数

| 内容长度 | 建议页数 | 每页格数 |
|---------|---------|---------|
| 短（<1000 字） | 4-6 页 | 4-5 格 |
| 中（1000-2000 字） | 8-12 页 | 4-6 格 |
| 长（>2000 字） | 15-25 页 | 3-5 格 |

### 4. 提升效果的技巧

- **开头要抓人**：第一格决定读者是否继续
- **节奏要变化**：快慢结合，避免单调
- **视觉要丰富**：远景、中景、特写交替
- **情绪要饱满**：用色彩和构图传达情绪
- **结尾要有力**：留下深刻印象

## 常见问题

### Q: 如何保证角色一致性？

A: 
1. 在第一格生成后，使用 `--cref` 参数引用
2. 在每个 Prompt 中包含完整的角色描述
3. 保持风格参数一致（--s 值）
4. 必要时手动后期调整

### Q: 如何控制信息密度？

A: 
- 每格只放 1-2 个要点
- 对话不超过 20 字/句
- 使用视觉隐喻代替文字解释
- 调整布局类型（dense/standard/cinematic）

### Q: 如何让漫画更有趣？

A: 
- 加入幽默元素
- 使用夸张的表情和动作
- 设计可爱的角色
- 添加视觉彩蛋

### Q: 生成的图片不满意怎么办？

A: 
- 调整 Prompt 的描述
- 修改 --s 参数（风格化程度）
- 尝试不同的风格
- 多生成几次选择最好的
