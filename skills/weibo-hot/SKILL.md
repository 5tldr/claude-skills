# 微博热搜分析

## 触发条件

当用户需要了解微博热搜、舆情动态、或热点事件时激活。

## 热搜分析框架

### 热搜类型

| 类型 | 标识 | 特点 |
|------|------|------|
| 自然热搜 | 无标识 | 用户自发讨论 |
| 新时代 | 新 | 新上榜话题 |
| 沸腾 | 沸 | 讨论度极高 |
| 热门 | 热 | 持续热议 |
| 商业推广 | 商 | 付费推广 |

### 热搜分类

```markdown
## 热搜类别

### 娱乐八卦
- 明星动态、影视综艺、粉丝互动
- 特点：爆发快，消退也快

### 社会民生
- 社会事件、民生问题、政策解读
- 特点：讨论深入，持续时间长

### 体育赛事
- 比赛结果、运动员动态
- 特点：时效性强，情绪化

### 科技数码
- 产品发布、行业动态
- 特点：垂直用户关注

### 财经商业
- 股市、企业新闻、经济政策
- 特点：专业性强
```

## 舆情分析框架

### 舆情生命周期
```
1. 萌芽期：少量讨论，尚未引起关注
2. 发展期：讨论增加，开始上热搜
3. 爆发期：大量转发，全网关注
4. 衰退期：热度下降，新热点替代
5. 长尾期：偶尔被提及
```

### 情感分析维度
| 情感 | 关键词示例 |
|------|------------|
| 正面 | 支持、点赞、厉害、感动 |
| 负面 | 失望、愤怒、抵制、差评 |
| 中立 | 围观、吃瓜、了解、关注 |

## 热点追踪策略

### 追热点时机
```
✅ 适合追的热点：
- 与自身领域相关
- 正面积极的话题
- 有独特观点可输出
- 热度上升期

❌ 不适合追的热点：
- 敏感政治话题
- 负面争议事件
- 与领域无关
- 热度已过峰值
```

### 内容角度
```
1. 科普解读：专业角度解释事件
2. 观点输出：表达独特见解
3. 关联延伸：与自身内容关联
4. 情感共鸣：引发用户共情
```

## 注意事项

1. **时效性**：热搜变化快，需及时跟进
2. **真实性**：核实信息来源，避免传谣
3. **合规性**：避免敏感话题
4. **理性分析**：客观看待舆情，不带节奏
