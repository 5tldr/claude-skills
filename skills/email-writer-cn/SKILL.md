# 中文商务邮件写作

## 触发条件

当用户需要撰写工作邮件、商务沟通、或正式书信时激活。

## 邮件结构

### 基本框架
```
【主题行】简洁明了，包含关键信息
【称呼】尊敬的XX / XX老师 / XX总
【开头】问候 + 自我介绍（如需要）
【正文】目的 + 详情 + 请求
【结尾】感谢 + 期待回复
【落款】祝好 + 署名 + 联系方式
```

### 主题行公式
```
[类型] + [核心内容] + [时间/紧急度]

示例：
- 【请示】关于Q1预算调整的审批申请
- 【汇报】12月项目进度周报
- 【邀请】1月15日产品发布会邀请函
- 【紧急】服务器故障处理进展
```

## 写作技巧

### 语气把控
| 对象 | 语气 | 示例 |
|------|------|------|
| 上级 | 尊敬、谦逊 | "请您指示"、"妥否请批示" |
| 平级 | 友好、专业 | "麻烦您"、"感谢配合" |
| 下级 | 清晰、鼓励 | "请于...完成"、"辛苦了" |
| 客户 | 热情、专业 | "感谢信任"、"竭诚为您服务" |

### 常用敬语
```
开头：您好 / 展信佳 / 见字如面
结尾：祝好 / 顺祝商祺 / 祝工作顺利
请求：烦请 / 敬请 / 恳请
感谢：感谢 / 多谢 / 不胜感激
```

### 避免事项
- ❌ 主题行空白或模糊
- ❌ 正文过长无分段
- ❌ 语气过于随意
- ❌ 忘记附件
- ❌ 群发邮件暴露收件人
