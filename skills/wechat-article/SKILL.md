# 公众号文章生成器

## 触发条件

当用户需要创作公众号文章、微信推文、或长文内容时激活。

## 平台特性

- **阅读场景**：碎片化时间、移动端为主
- **内容深度**：比小红书更深，比知乎更易读
- **核心价值**：信息增量、情感共鸣、实用价值

## 文章结构

### 标题公式

**公式A：悬念+利益**
```
❌ AI工具推荐
✅ 用了这5个AI工具后，我每天多出2小时
```

**公式B：数字+场景+结果**
```
❌ 职场沟通技巧
✅ 3个说话公式，让领导对你刮目相看
```

**公式C：反常识+颠覆**
```
❌ 学习方法分享
✅ 为什么越努力学习，成绩反而越差？
```

### 文章框架

```markdown
【标题】吸引点击

【开头】（前100字决定是否继续）
- 故事开场：一个具体场景/案例
- 痛点开场：直击读者困扰
- 数据开场：惊人数据引发好奇

【正文】
- 小标题分段，每段300-500字
- 金句穿插，便于转发
- 案例+方法论结合

【结尾】
- 总结升华
- 引导互动（在看、转发、留言）
```

## 文章类型模板

### 干货教程型
```
你有没有遇到过这种情况？

[描述痛点场景]

今天，我要分享[X]个方法，帮你彻底解决这个问题。

---

### 方法一：[名称]

[具体操作步骤]

> 关键点：[核心要点]

### 方法二：[名称]

[具体操作步骤]

> 关键点：[核心要点]

---

最后，总结一下今天的内容：
1. [要点1]
2. [要点2]
3. [要点3]

如果觉得有用，点个「在看」，分享给需要的朋友。
```

### 观点输出型
```
最近，[热点事件/现象]引发了很多讨论。

有人说[观点A]，也有人说[观点B]。

但我认为，[你的观点]。

为什么这么说？

---

### 第一，[论点1]

[论据和分析]

### 第二，[论点2]

[论据和分析]

### 第三，[论点3]

[论据和分析]

---

所以，[结论]。

你怎么看？欢迎在评论区留言讨论。
```

### 故事案例型
```
[人物]的故事，值得每个人看看。

[故事开头 - 设置悬念]

---

[故事发展]

---

[故事高潮]

---

[故事结局]

---

这个故事告诉我们：

[道理/启发]

> [金句总结]
```

## 写作技巧

1. **开头3秒定生死**：前100字必须抓住注意力
2. **小标题是骨架**：让读者快速了解文章结构
3. **金句是灵魂**：便于读者截图转发
4. **结尾要有力**：引导互动，提升数据
5. **排版要舒适**：多留白，少大段文字
