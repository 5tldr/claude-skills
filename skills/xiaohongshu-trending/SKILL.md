# 小红书热门趋势分析

## 触发条件

当用户需要了解小红书热门话题、内容趋势、或选题灵感时激活。

## 功能说明

由于小红书没有公开API，本Skill提供：
1. 热门话题分析框架
2. 趋势判断方法
3. 选题策略建议

## 热门分析框架

### 热门类型

| 类型 | 特点 | 生命周期 |
|------|------|----------|
| 节日热点 | 可预测，流量大 | 节前1-2周 |
| 社会热点 | 突发，流量爆发 | 1-3天 |
| 平台活动 | 官方推流 | 活动期间 |
| 长青话题 | 持续有流量 | 长期 |

### 热门赛道

```markdown
## 🔥 高流量赛道

### 美妆护肤
- 热门话题：#早C晚A #成分党 #平价好物
- 内容形式：测评、教程、空瓶记
- 流量特点：稳定，竞争激烈

### 穿搭时尚
- 热门话题：#OOTD #小个子穿搭 #通勤穿搭
- 内容形式：穿搭公式、单品推荐
- 流量特点：季节性强

### 美食探店
- 热门话题：#探店 #美食推荐 #[城市]美食
- 内容形式：探店vlog、食谱教程
- 流量特点：地域性强

### 家居生活
- 热门话题：#好物分享 #收纳整理 #租房改造
- 内容形式：开箱、改造前后对比
- 流量特点：转化率高

### 职场成长
- 热门话题：#打工人 #副业 #面试技巧
- 内容形式：干货分享、经验总结
- 流量特点：互动率高

### 母婴育儿
- 热门话题：#育儿经验 #宝宝辅食 #孕期日记
- 内容形式：经验分享、好物推荐
- 流量特点：用户粘性高
```

## 趋势判断方法

### 数据指标
```
1. 搜索热度：搜索框下拉词变化
2. 话题热度：话题页浏览量
3. 笔记增量：同话题新笔记数量
4. 互动数据：点赞/收藏/评论比例
```

### 判断维度
```
✅ 上升趋势信号：
- 搜索下拉词新增
- 同类笔记爆款增多
- 评论区讨论活跃
- 官方话题推荐

⚠️ 下降趋势信号：
- 同质化内容过多
- 用户审美疲劳
- 新爆款难以出现
```

## 选题策略

```markdown
## 热点结合公式

[热点] + [你的领域] = 选题
```

## 注意事项

1. **时效性**：热点变化快，需要及时跟进
2. **差异化**：避免完全复制，要有自己的角度
3. **合规性**：避免敏感话题和违规内容
4. **真实性**：不要为了蹭热点而虚假宣传
